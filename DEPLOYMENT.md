# Размещение IMG_LIB на GitHub Pages

Сайт состоит из статических файлов и не требует сборки или установки зависимостей. Главная страница — `index.html`, оформление — `styles.css`, значок вкладки — `favicon.svg`. Файл `.nojekyll` отключает обработку Jekyll. Все ресурсы подключены относительными путями, подходящими для сайта в подпапке репозитория.

## Публикация

1. Добавьте файлы из этой папки в корень выбранной ветки GitHub-репозитория, включая `.nojekyll`, и отправьте изменения на GitHub.
2. В репозитории откройте **Settings → Pages**.
3. В **Build and deployment → Source** выберите **Deploy from a branch**.
4. Укажите ветку с файлами сайта и каталог **/(root)**, затем нажмите **Save**.
5. Дождитесь завершения развёртывания. Адрес опубликованного сайта появится в настройках Pages.

Порядок настройки описан в [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## Локальный просмотр

Можно открыть `index.html` в браузере напрямую. Для проверки через HTTP выполните в этой папке:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Затем откройте <http://127.0.0.1:8080/>. Для остановки сервера нажмите Ctrl+C.

## Ссылки на скачивание

В секции `id="download"` файла `index.html` подключены два файла:

- инсталлятор — `./Releases/win-x86/Oblteh.ImgLib-win-x86-Setup.exe`;
- переносимая версия — `./Releases/win-x86/Oblteh.ImgLib-win-x86-Portable.zip`.

Ссылки используют относительные пути и атрибут `download`. При публикации разместите оба файла в каталоге `Releases/win-x86` относительно `index.html`, сохранив регистр имён. При замене файлов с теми же именами менять ссылки в HTML не требуется.
